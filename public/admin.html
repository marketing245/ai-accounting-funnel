Meta (Facebook / Instagram)

With META_PIXEL_ID + META_CAPI_TOKEN set, every checkout sends InitiateCheckout and every payment sends Purchase server-side (Conversions API) with hashed email, phone, name, fbp/fbc, IP and user agent — de-duplicated with the browser pixel by event id. The CSV is the fallback for manual offline uploads.

What fires on every order

• GA4 (browser): page_view, begin_checkout, add_payment_info, purchase (with transaction_id, value, tax, items) → import "purchase" into Google Ads as a conversion.
• Google Ads tag (browser): conversion event with transaction_id + enhanced conversions (hashed email/phone/name) — needs GOOGLE_ADS_ID + label in site-config.js.
• Meta pixel (browser): InitiateCheckout, AddPaymentInfo, Purchase with eventID = order id — needs META_PIXEL_ID in site-config.js.
• Meta CAPI (server): InitiateCheckout + Purchase — see status above; per-order result is in the order drawer.
• Stored on every order: utm_source/medium/campaign/term/content/id, gclid, gbraid, wbraid, fbclid, ttclid, msclkid, referrer, landing page, first touch + last touch + up to 10 touches, device/OS/browser, country/city, sessions & pageviews before buying, hours from first visit to purchase.
