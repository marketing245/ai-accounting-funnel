# AI Accounting Engineer — Marketing Funnel Engine & Simulator

Interactive marketing funnel visualizer, simulator, and unit economics engine built for the **AI in Accounting** course by **CA Varsha Varyani** (Base Checkout: [superprofile.bio/course/633d8759-74c2-43e2-9141-ac89ef39cd04](https://superprofile.bio/course/633d8759-74c2-43e2-9141-ac89ef39cd04)).

---

## 🚀 Funnel Architecture Variations

1. **Variation 1: Direct-to-Offer + Order Bump & One-Click Upsell (The Scale Funnel)**
   - **Entry:** Meta Video Ads (Reels) targeting late-night close frustrations.
   - **Order Bump:** ₹399 ("50+ Ready Claude Accounting Prompts & SOP Pack") added via one-click checkbox.
   - **Post-Purchase Upsell (OTO):** ₹2,999 ("4-Week Saturday Live Implementation Cohort").
   - **AOV Impact:** Lifts average order value from ₹1,499 to **₹2,109+** (+40.7%), enabling aggressive ad bidding on Meta.

2. **Variation 2: Free Lead Magnet + WhatsApp Nurture (Lowest CAC)**
   - **Entry:** Instagram Reel / Comment Automation ("Comment PROMPT for 35 Claude Prompts").
   - **Nurture:** 4-Day automated WhatsApp drip (90%+ open rate vs 20% on email).
   - **Conversion:** Day 3 limited-time founding cohort flash offer.

3. **Variation 3: ₹99 Live Sunday Workshop (High Trust & High Ticket)**
   - **Entry:** Paid ₹99 Zoom Masterclass.
   - **Show-up Rate:** 60%+ (vs 18% for free webinars).
   - **Pitch:** Live bank rec & GST matching demo -> 22% in-webinar conversion to full bundle.

4. **Variation 4: LinkedIn Organic Thought Leadership (Zero Ad Spend)**
   - **Entry:** Teardowns, Before vs After carousels, salary benchmark posts.
   - **Automation:** Comment-to-DM Manychat automation to distribute Module 1.

5. **Variation 5: CA Firm Team License (High-Ticket B2B)**
   - **Entry:** B2B packages for CA practice partners (5 to 25 seats @ ₹9,999 - ₹24,999).
   - **Angle:** Retain articles, eliminate compliance backlog, and handle 2x clients.

## 🛠️ Tech Stack & Deployment

- **Runtime:** Node.js (Zero external npm dependencies, pure standard library).
- **Frontend:** Responsive SPA with Tailwind CSS & custom design system.
- **Port:** Configurable via `PORT` environment variable (defaults to 3000).
- **Deployment:** 1-Click ready for **Railway**, Vercel, Docker, or any Node host.

## 🏃 Quick Start Locally

```bash
git clone https://github.com/manak-debug/ai-accounting-funnel.git
cd ai-accounting-funnel
node server.js
```

Visit `http://localhost:3000` in your browser.
